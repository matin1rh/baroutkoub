# راهنمای اجرای کامل و ساخت فایل نصبی ویندوز (.exe)
### سامانه هوشمند تطبیق و مغایرت‌گیری بانکی باروتکوب

این پروژه به گونه‌ای طراحی و سازماندهی شده است که به راحتی در محیط ویندوز (Windows 10 / 11 / Server) به دو روش قابل اجرا و استفاده است:

---

## روش اول: اجرای تک‌کلیک و سریع در ویندوز (بدون نیاز به تنظیمات پیچیده)

1. مطمئن شوید **[Node.js](https://nodejs.org)** روی ویندوز نصب است (نسخه 18 به بالا).
2. فایل‌های پروژه را استخراج (Extract) کنید.
3. روی فایل **`start_windows.bat`** دابل کلیک کنید.
4. برنامه به طور خودکار همه پکیج‌ها را بررسی، بیلد و در مرورگر با آدرس `http://localhost:3000` اجرا می‌کند.

---

## روش دوم: ساخت فایل نصبی مستقل ویندوز (Desktop Application / .exe)

اگر می‌خواهید این برنامه مثل یک نرم‌افزار دسکتاپ اختصاصی با پنجره و آیکون مجزا اجرا شود:

1. روی فایل **`build_windows_exe.bat`** دابل کلیک کنید (یا در ترمینال دستور `npm run electron:build` را اجرا کنید).
2. ابزار Electron Builder فایل اجرایی و نصبی ویندوز را در پوشه `dist` می‌سازد.
3. فایل ساخته شده را می‌توانید در هر کامپیوتر ویندوزی بدون نیاز به نرم‌افزار جانبی نصب و اجرا کنید.

---

## اسکریپت‌های موجود در پروژه:

- `start_windows.bat`: راه‌اندازی و اجرای آنی پروژه با ۱ کلیک در ویندوز
- `build_windows_exe.bat`: ساخت فایل نصبی EXE دسکتاپ ویندوز
- `npm run dev`: اجرای محیط توسعه
- `npm run build`: ساخت کدهای بهینه شده
- `npm start`: اجرای سرور نسخه نهایی
